# موقع د. دلال العصيمي

صفحة واحدة (one-page) لأخصائية نفسية للأطفال والمراهقين، مبنية من تصميم Figma،
مع **نظام حجز تفاعلي** في أسفل الصفحة.

A single-page Arabic (RTL) site for a child & adolescent psychologist, built from
the Figma design, with an interactive reservation flow at the bottom.

---

## التشغيل / Running it

لا يوجد أي build step ولا تبعيات (dependencies). افتح `index.html` مباشرة، أو
شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### النشر / Deploying

المشروع ملفات ثابتة فقط، فهو يعمل على أي استضافة: GitHub Pages، Netlify،
Vercel، Cloudflare Pages، أو أي خادم عادي. ارفع المجلد كما هو.

## البنية / Structure

```
index.html                  ← كامل محتوى الصفحة
assets/css/styles.css       ← التنسيقات + متغيّرات التصميم (design tokens)
assets/js/booking.js        ← نظام الحجز  ← كل الإعدادات هنا
assets/js/main.js           ← الهيدر، قائمة الجوال، التأثيرات
assets/images/              ← صور مؤقتة (انظر assets/images/README.md)
```

الأقسام بالترتيب: الهيدر ← القسم الرئيسي ← الخدمات ← نبذة عني ← قصص العملاء
← الحجز ← الفوتر.

## ⚙️ إعداد نظام الحجز / Configuring the booking system

كل ما تحتاج تعديله موجود في كتلة `CONFIG` أعلى ملف
[`assets/js/booking.js`](assets/js/booking.js).

### 1. استقبال الحجوزات على بريدك

النموذج حاليًا يعمل في **وضع تجريبي (demo mode)**: يتحقق من البيانات ويعرض
شاشة النجاح، لكنه **لا يرسل أي شيء**. لتفعيل الإرسال الفعلي:

1. أنشئ حسابًا مجانيًا على <https://web3forms.com> وأدخل بريدك.
2. ستصلك رسالة فيها `Access Key`.
3. ضعه مكان القيمة الافتراضية:

```js
accessKey: 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx',
```

بمجرد وضع المفتاح، كل حجز يصلك على البريد مباشرة بكل التفاصيل (الاسم، اسم
الطفل وعمره، البريد، الخدمة، نوع الجلسة، التاريخ، الوقت، المدة، السعر).

> يمكن استبدال Web3Forms بأي خدمة أخرى (Formspree، Getform…) بتغيير `endpoint`
> وشكل الـ `payload()`.

### 2. أنواع الجلسات والأسعار

```js
sessionTypes: [
  { id: 'intro', label: 'جلسة تعريفية', minutes: 50, price: 100 },
  ...
]
```

`minutes` بالدقائق و `price` بالريال. الملخص والسعر في النموذج يتحدّثان تلقائيًا.

### 3. ساعات العمل

```js
hours: {
  0: { from: '09:00', to: '12:00' },   // الأحد
  ...
  5: { from: '19:00', to: '22:00' }    // الجمعة
},
step: 30                                // المسافة بين المواعيد بالدقائق
```

الأرقام `0`–`6` هي أيام الأسبوع (0 = الأحد). احذف أي يوم لجعله يوم إجازة.
القيم الحالية مطابقة لساعات العمل المكتوبة في الفوتر.

### 4. المواعيد المحجوزة

**مهم:** لا يوجد خادم (back-end)، فالصفحة لا تعرف ما هو محجوز فعلًا. أضف
المواعيد المحجوزة يدويًا:

```js
booked: { '2026-10-05': ['09:30', '11:00'] },
```

وهناك خيار `demoUnavailable: true` يُظهر بعض المواعيد باللون الباهت فقط لتوضيح
شكل الحالة "غير متاح" — **اجعله `false`** عند ربط التوفّر الحقيقي.

### 5. نافذة الحجز

```js
minDaysAhead: 0,    // 0 = يمكن الحجز اليوم، 1 = من الغد
maxDaysAhead: 90,   // أبعد يوم يمكن الحجز فيه
weekStart: 5        // أول عمود في التقويم (5 = الجمعة، مطابق للتصميم)
```

## ما يقوم به النموذج

- اختيار الخدمة ونوع الجلسة (مع المدة والسعر).
- تقويم ميلادي بالعربية، تنقّل بين الأشهر، والأيام غير المتاحة معطّلة.
- مواعيد تُولَّد تلقائيًا من ساعات العمل، والمواعيد التي مضت اليوم تُخفى.
- ملخص حجز يتحدّث مباشرة.
- تحقّق من البيانات برسائل خطأ عربية أسفل كل حقل.
- شاشة تأكيد بعد الإرسال، مع إمكانية "حجز موعد آخر".
- يعمل بالكامل بلوحة المفاتيح (أسهم التنقّل داخل التقويم)، مع `aria-label`
  و `aria-pressed` و `aria-live` للملخص.

## ملاحظات على التنفيذ / Implementation notes

**الخطوط.** التصميم يستخدم `Thmanyah Sans`، وهو خط غير متاح على Google Fonts.
الصفحة تطلبه أولًا، ثم تعود إلى `IBM Plex Sans Arabic` (وهو الخط الثاني
المستخدم في التصميم نفسه ويُحمَّل من Google Fonts). إن كان لديك ترخيص
Thmanyah Sans، أضف `@font-face` في أعلى `styles.css` وسيُستخدم تلقائيًا.

**الصور.** لم يكن الوصول إلى صور Figma ممكنًا أثناء البناء، لذا كل الصور في
`assets/images/` هي صور SVG مؤقتة. التفاصيل ومقاسات الاستبدال في
[`assets/images/README.md`](assets/images/README.md). الشعار والأيقونات
النباتية والأيقونات داخل البطاقات مرسومة يدويًا كـ SVG داخل الصفحة.

**القائمة.** روابط `طريقة العمل` و `الاسئلة الشائعة` و `تواصل معنا` كانت في
تصميم الهيدر لكن لا توجد لها أقسام في التصميم، فحُذفت من القائمة (والفوتر)
وبقيت الأقسام الموجودة فعلًا فقط.

**بطاقات الخدمات.** التصميم يحتوي على خمس بطاقات، اثنتان منها متطابقتان
(«استشارات الزواج والعلاقات الزوجية» مكرّرة). البطاقة الخامسة هنا
«استشارات الأطفال والمراهقين» بنص مبدئي — عدّلها كما تشاء.

**الألوان.** متغيّرات CSS في أعلى `styles.css` مطابقة لمتغيّرات Figma حرفيًا
(`--primary: #1A5038`، `--secondary: #BC953E`، وهكذا).
