# صور الموقع / Site images

الملفات هنا **صور مؤقتة (placeholders)** رُسمت بصيغة SVG، لأن تحميل الصور
الأصلية من Figma كان محجوبًا في بيئة التطوير.

These are **placeholders**. Replace them with the real photography.

| الملف | الاستخدام | المقاس المقترح |
|---|---|---|
| `hero.svg`    | صورة القسم الرئيسي | 445 × 539 (نسبة 1:1.21) |
| `about.svg`   | صورة "نبذة عني"    | 285 × 345 |
| `avatar-1..3.svg` | صور آراء العملاء | 52 × 52 (مربعة) |
| `favicon.svg` | أيقونة المتصفح     | 48 × 48 |

## كيف تستبدلها

ضع الصورة الحقيقية هنا ثم عدّل المسار في `index.html`، مثلًا:

```html
<img src="assets/images/hero.jpg" alt="..." width="445" height="539">
```

الشعار في الهيدر والفوتر مرسوم مباشرة داخل `index.html` كـ SVG — استبدله
بشعارك الحقيقي عند توفره.
